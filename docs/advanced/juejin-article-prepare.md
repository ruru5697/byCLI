# 掘金文章发布准备

`juejin publish-article --prepare`只完成准备。独立review、submit和status模式已实现，见[提交、状态与数据说明](juejin-article-publish-stats.md)。它使用原生 Page → daemon → Chrome 扩展链路，在已登录的掘金 Markdown 编辑器中填写正文、上传封面、选择分类和标签、填写摘要。准备会创建或自动保存远端草稿并上传图片，成功并不表示已发布。

```bash
node dist/src/main.js juejin publish-article --prepare --input article.json --timeout 300 -f json
```

清单示例：

```json
{
  "title": "我的 Bug 递交了辞职信",
  "body": "Markdown 正文，使用 LF 换行。",
  "cover": "cover.png",
  "summary": "这里填写五十到一百个字符单位的单行摘要，概括文章主题与主要内容。命令会实际填写并检查编辑器显示值、草稿模型与关闭重开后的保存值。",
  "category": "代码人生",
  "tags": ["程序员"],
  "columns": [],
  "topics": [],
  "visibility": "public",
  "accountId": "预期账号的公开数字ID"
}
```

当前范围：标题1–100、正文1–100000、摘要50–100个JavaScript字符单位；这些是本命令的输入范围，不宣称已实测平台全部边界。正文保留原始Markdown，包括换行、标题、列表、引用和代码围栏；暂不支持行内图片、视频或活动HTML。正文图片需要独立的上传与来源核对，不能用外链代替已验证上传。

分类显式选择后端、前端、Android、iOS、人工智能、开发工具、代码人生、阅读之一。当前实际账号的标签上限为1，本版只支持一个准确匹配的现有标签；搜索不到就停止，不选择相近名称。专栏和话题必须显式为空，不同步到组织。public表示准备默认公开发布候选，不证明审核通过或线上已公开；当前面板未见独立私密/定时开关，也不支持这些设置。

封面支持小于5 MiB的PNG/JPEG，至少192×128，严格3:2比例，减少信息流缩略图裁切。路径相对JSON文件解析。上传前计算SHA256；在网站清空文件输入前，再对浏览器选中的File计算SHA256和大小。等待预览加载、尺寸一致、图片与草稿模型绑定、自动保存完成后才检查持久化。

掘金会为私有素材生成临时访问地址，因此封面身份按经验证域名下的稳定存储对象计算摘要，不比较临时签名。报告不保存上传地址、签名、令牌或完整账户资料。平台可能压缩、转码和加水印，本地与远端图片不做字节一致性声明。

命令关闭并重开唯一受控标签页，重新核对账号、草稿ID、标题、完整Markdown及摘要、分类标签、封面资源、专栏话题和组织同步状态。完成后保留发布面板供验收，不点击“确定并发布”。底部按钮可能在窗口下方，验收截图会滚动至按钮位置。

## 页面保护与失败恢复

仅允许从空白新稿或已知安全入口开始；已有草稿、文章或未知页面返回EXISTING_EDITOR。页面自动恢复非空内容也停止。不会通过同会话新开第二个标签绕过编辑器保护。

失败后在私有报告里记录阶段、错误码和核对过的草稿ID，保留页面。仅失败且未提交、没有提交尝试的同账号任务允许恢复：

```bash
node dist/src/main.js juejin publish-article --prepare --resume JOB_UUID --input article.json -f json
```

恢复前必须确认当前唯一受控页面的账号、草稿ID、原标题和原正文与失败任务完全一致。清单内容可按用户要求更新，报告记录清单修订摘要；手工修改了原稿、换了账号或页面时停止，不覆盖。现有标签如果与新清单不一致也停止，需先人工处理。已准备成功的任务不允许再用resume覆盖；prepare模式不会调用submit；独立提交模式需要另行授权和有效确认码。作业独占锁防止并行改写同一本地报告；进程异常退出遗留的锁须检查后处理，不自动抢占。

本机账号绑定的验收素材、回执和实验脚本不随包分发。可用性与验证范围见[原生连接器说明](../guide/native-connectors.md)。

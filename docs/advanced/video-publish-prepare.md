# 视频发布准备：小红书与搜狐号

`publish-video --prepare` 只上传、填写并校验编辑器，不提交发布。现在提供独立的 `--review`、`--submit --confirm` 和 `--status` 模式；必须先检查当前账号与内容，取得人工发布同意后，才能运行提交模式。

前提是本地 Chrome 中的 byCLI 扩展连接正常、对应创作平台已经登录，账号具备上传权限，网络可以访问视频和图片上传服务。命令会激活自己的页面，以便封面编辑器和动画正常完成。

## 使用方式

在仓库本地构建后运行：

```bash
npm run build
node dist/src/main.js xiaohongshu publish-video --input ./xhs-video.json --prepare --timeout 300 -f json
node dist/src/main.js sohu publish-video --input ./sohu-video.json --prepare --timeout 300 -f json
```

两个平台串行执行。命令默认使用平台持久会话，保留已准备页面供人工检查；每个平台只保留一个编辑页。准备流程可能上传远端素材或触发站点自动保存，不等同于草稿持久化成功。检查完不再使用的实验页请关闭。

不要在已有编辑内容的同一会话中重复准备：命令会返回 `EXISTING_EDITOR`，避免覆盖当前内容。先检查并关闭旧编辑页，再准备新内容。若会话失效，可以在清理不用的实验页后用 `--site-session ephemeral --keep-tab true` 建立新会话；仍应将总实验页数限制为两个。

`--timeout` 为外层命令总超时，默认 300 秒；上传完成、封面和必填项各自还有内部状态等待上限。该参数不会触发自动重新上传。超时后先检查原页面与作业报告，确认之前操作的结果，不要盲目重跑。验证码和账号补充信息需要人工处理。

## 小红书输入

```json
{
  "video": "/absolute/path/video.mp4",
  "cover": "/absolute/path/cover.png",
  "title": "视频标题",
  "body": "笔记正文",
  "declaration": "none",
  "visibility": "public",
  "coverRatio": "4:3"
}
```

路径也可相对于 JSON 文件所在目录。标题 1–20 个 JavaScript 字符单位，正文 1–1000；不静默截断。`coverRatio` 可省略，或为 `原始`、`1:1`、`3:4`、`4:3`。指定数值比例时，还会检查主封面实际显示的比例。

`declaration` 必须显式给出，支持 `none`、`虚构演绎，仅供娱乐`、`笔记含AI合成内容`、`内容包含营销广告`。`none` 表示不额外声明，不会自动操作原创声明；应按真实内容填写。本轮真实准备验收使用 `none`，另实测了 AI 内容声明的选择和读回，其他组合未逐个进行网站端到端验收。当前仅支持公开可见，不静默忽略其他可见性或额外字段。

视频上传完成后，程序进入封面编辑器，通过“上传封面”上传独立图片，确认裁剪，检查封面已替换且弹窗关闭，再填写正文。最后核对视频预览、标题正文、声明、可见性及发布控件状态。不会调用发布控件的方法。

## 搜狐号输入

```json
{
  "video": "/absolute/path/video.mp4",
  "cover": "/absolute/path/cover.png",
  "title": "视频标题至少五字",
  "body": "视频简介至少五字",
  "category": ["科技", "电脑"],
  "declaration": "无需声明",
  "visibility": "public"
}
```

标题 5–72、简介 5–200 个 JavaScript 字符单位。分类必须提供一级和二级名称，必须是当前后台确实存在的组合。命令通过页面选择两级分类，不直接写内部编号。

声明可为 `无需声明`、`含有虚构演绎内容`、`含有AI生成内容`、`含有营销信息`、`内容为转载`、`内容为个人观点`。本轮真实验收为“科技 / 电脑”和“无需声明”；其他声明组合尚未逐个完成网站端到端验收。补充声明、来源链接、话题、栏目等未在本版本支持，输入这些额外字段会报错。涉及这些条件的业务内容需补充相应流程后再验收，不能仅因基本准备通过就直接发布。

程序等待网站明确显示视频上传成功，打开独立封面素材弹窗、上传并确认一张封面，再填写标题简介、频道分类、必选声明，等待额度加载后核对。公开可见沿用该视频编辑页的平台默认；当前没有提供其他可见性设置。

## 素材、结果与恢复

当前视频限定 MP4，并做原生容器与视频轨结构检查；封面限定 PNG/JPEG，最大 10 MiB。搜狐封面宽度必须大于 450、高度大于 300。视频文件上限按网站提示分别限制为搜狐 4 GiB、小红书 20 GiB，实际站点还可能有时长、编码、额度等限制。网站拒绝、处理中或超时都不能算准备成功。日常命令不需要 ffmpeg/ffprobe。

成功返回：

```json
[
  {
    "status": "ready_for_confirmation",
    "job_id": "生成的作业编号",
    "submitted": false,
    "report": "/用户状态目录/publish-jobs/平台/作业编号/job.json",
    "preview": "/用户状态目录/publish-jobs/平台/作业编号/preview.png"
  }
]
```

状态目录默认 `~/.bycli`，可使用已有 `BYCLI_CONFIG_DIR` 配置。作业报告保存素材摘要、输入摘要、当前步骤、页面标识、字段回读和截图路径；不保存登录 Cookie、签名上传地址或请求头。文件权限限制为当前用户访问。

`ready_for_confirmation` 表示当前编辑器的已知字段与素材经过检查，不表示平台已经接受正式发布，也不保证远端草稿持久化。作业仅是此次准备的快照，关闭页面后不能把报告当作可直接继续提交的令牌；不能自动恢复已关闭的准备编辑器。正式提交使用下述 review/submit 流程，并重新核对当前账号、页面与内容。

失败报告区分输入错误、已有编辑器、站点拦截、网络不可达、上传/处理超时和字段不一致等。若进程被强制终止，最后保存的阶段可能停在 `preparing`；应结合进程和页面状态检查，不将本地快照误当成实时状态。

截图反映实际页面视口；部分网站使用内部滚动容器，`fullPage` 截图也可能无法同时包含全部字段。必填项结果需结合报告中的 `checks` 和实际页面检查。

本机账号绑定的验收素材、回执和实验脚本不随包分发。可用性与验证范围见[原生连接器说明](../guide/native-connectors.md)。


## 提交、回执和状态查询（第二期）

以下命令中的 UUID、TOKEN 均来自本机对应作业，不能使用别的平台或另一条作业的值。四种模式互斥；只有准备模式接受 `--input`。确认码是防误操作参数，不能代替操作者取得用户的明确发布授权。

```bash
# 生成当前内容预览和 30 分钟有效的确认码，不提交
node dist/src/main.js xiaohongshu publish-video --review JOB_UUID -f json
node dist/src/main.js sohu publish-video --review JOB_UUID -f json

# 仅在用户看过账号、内容、预览并明确同意正式公开发布后执行
node dist/src/main.js xiaohongshu publish-video --submit JOB_UUID --confirm TOKEN -f json
node dist/src/main.js sohu publish-video --submit JOB_UUID --confirm TOKEN -f json

# 查询本地作业，存在精确作品 ID 时查询平台内容管理页
node dist/src/main.js xiaohongshu publish-video --status JOB_UUID -f json
node dist/src/main.js sohu publish-video --status JOB_UUID -f json
```

新准备作业会绑定平台账号标识、网站已上传视频标识与封面指纹。`--review` 重新校验本地素材 SHA-256、标题正文、公开可见、分类声明、上传完成、封面状态及发布额度，保存 `confirmation.png` 与账号名称。确认时还绑定可见编辑器设置。切换账号、更换视频封面、修改字段或设置都会阻止提交。确认过期须重新 review；素材或账号变化则须重新准备。旧一期作业首次 review 才建立媒体绑定，验收优先使用新准备作业。

提交前使用本地独占作业锁，并把唯一 attempt 写入文件，随后才触发一次网站最终发布控件。小红书通过不自动重试的evaluateOnce只调用一次当前已验证存在的 `_onPublish`，搜狐只点击唯一可见“发布”。调用抛错后不尝试其他方法，也不再次点击。原生网络捕获不可用时，提交会在点击前失败。

网络捕获是读取即清空的缓冲区。提交后等待 25 秒，再读取一次对应 POST 接口回执，避免轮询清掉尚未返回的响应正文。只接受精确接口、HTTPS、正确平台域名、完整 JSON、成功 HTTP 与明确平台业务状态。回执仅持久化白名单字段（业务码、HTTP 状态、作品 ID、时间），不保存完整请求响应、Cookie、鉴权头或签名素材地址。业务成功但未知 ID 格式只表示已受理，不能按标题猜 ID；超时、截断、非 JSON 或矛盾响应均为结果不明。

| 状态 | 含义与处理 |
| --- | --- |
| `ready_for_confirmation` | 准备成功，尚未提交；review 后等待人工确认 |
| `submitting` | 已持久化一次提交尝试；中断恢复时按结果不明处理 |
| `accepted` | 平台业务回执已受理，尚不能声称审核通过或公开可见 |
| `reviewing` / `published` / `rejected` | 精确 ID 对应的后台审核中、已发布、拒绝状态；`rejected` 也可来自明确提交拒绝回执，来源见 receipt/lastQuery |
| `scheduled` / `draft` / `deleted` | 搜狐后台单条记录的相应状态 |
| `result_unknown` | 可能已提交，禁止自动重发；人工到后台核对 |

`submitted` 分别使用 `true`（明确受理）、`false`（尚未点击或明确拒绝）、`null`（尝试过但结果不明）。任何有 attempt 的作业都禁止再次提交，包括收到拒绝后；不得把重新准备另一作业当作结果不明后的自动补发办法。

`--status` 对未提交作业仅返回本地状态，不离开编辑器。已取得回执或人工核对作品 ID 的作业优先复用内容管理页；原页已关闭时，可重新打开管理页查询，并核对当前账号。原页仍是编辑器时返回EDITOR_IN_USE，不导航，也不在同一持久会话中新开替代查询标签，以保留编辑内容。已知分析页也可安全复用，避免累积实验标签。查询不会发布、存草稿或重试提交。

列表只读查询使用页面内 fetch/XHR 响应观察，等待完整响应，缓冲读取不清空尚未返回的响应；该观察方式不替代提交前的原生网络捕获保护。

小红书按“已发布/审核中/未通过”筛选的正常列表响应与精确 ID 判定，分别对应 tab=1/2/3；搜狐按 `newsType=4` 且账号匹配的视频列表中单条记录的 status 判定，不能混用查询筛选编号（单条 status=4 才是已发布，2 是审核中）。目前查询各筛选首屏，较旧内容未进入加载列表时返回 `query_status=not_found`；鉴权失败、网络慢于等待窗口或未取得有效列表返回 `query_unavailable`。这些查询结果不会覆盖已知发布状态，也不会被解释为作品已删除。返回的 `query_status/query_reason` 与作业 `lastQuery` 可供区分“最后已知状态”和“本次查询结果”。目前尚不自动翻页，不支持没有精确 ID 的结果不明作业自动认领。

作业使用 `job.json.lock` 防并发。强制结束进程可能遗留锁；必须先确认相关进程已退出，再人工移除该作业锁。即使移除锁，持久化的 attempt 仍会阻止重新提交。禁止直接删除 attempt 以绕过保护。

### 本期验收边界

本机账号绑定的验收素材、回执和实验脚本不随包分发。可用性与验证范围见[原生连接器说明](../guide/native-connectors.md)。

小红书首次回执仍保留未知状态，后续通过后台精确记录完成核对；新解析器对未知 JSON 保存 HTTP 状态、白名单结构字段、数据类型等诊断，仍不会按未知结构推断成功。没有通过额外发布来抓取响应。

## 单条视频数据

```bash
node dist/src/main.js xiaohongshu stats --content-id 000000000000000000000002 --account-id 1234567890 --scope content -f json
node dist/src/main.js sohu stats --content-id 123456003 --account-id 123456789 --type video -f json
```

建议始终指定 `--account-id`，避免切换账号后读取另一账号数据。小红书先在当前账号管理列表中以精确 ID 验证视频类型，再进入单篇详情读取展示字段。搜狐号进入“单篇 → 视频”，以签名列表响应中的精确 newsId/type/账号绑定页面行，并核对六个可见数值。

输出包含账号、内容ID、类型、来源、采集时间、后台统计时间（未提供时为null）、统计范围。每项指标包含原始标签/原始值、数值、可用性、精度、原因；0是真实零，`-`与未展示字段为null。万/亿为约数，带`+`为下界，百分比的数值单位为percent。

搜狐日期范围表示“所选时间段内发布的作品”的实时累计值，不是这段时间新增量；总览截止昨日24:00的数据不能代替今日视频统计。当前使用后台默认发布日期范围和列表第一页，小红书身份核验也受当前管理列表首屏限制；未命中明确报错或返回查询不可用，不补零或推断删除。当前未实现历史翻页、自定义日期和定时采集。

本机账号绑定的验收素材、回执和实验脚本不随包分发。可用性与验证范围见[原生连接器说明](../guide/native-connectors.md)。
